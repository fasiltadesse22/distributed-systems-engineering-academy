# Distributed Systems Engineering Academy

A React/TypeScript interactive learning academy for **enterprise distributed systems architecture and system design** at Senior/Staff engineering depth.

## Authoritative materials

- [Master Roadmap V1.0](docs/roadmap/MASTER_ROADMAP_V1.md) — 19 phases / 93 clusters with technical scope, interactive teaching briefs, real-application pressures and mastery standards.
- [Dual-Repository Execution Contract](docs/contracts/DUAL_REPOSITORY_EXECUTION_CONTRACT_V1.md) — required evidence, learning architecture and commit alignment.

## Companion real-world application

[Food Ordering Platform](https://github.com/fasiltadesse22/food-ordering-platform-new) is a **separate** Java/Spring Boot repository. The learning academy references reproducible experiments and immutable application checkpoints; it does not contain the production-oriented backend itself.

## Status

**Planning baseline only.** The React application, blueprint reader, lessons and interactive simulators have not yet been implemented or verified. This repository will evolve from scratch as the roadmap is executed.

## Learning contract

Orient → Understand → Explore → Predict → Engineer when justified → Verify → Diagnose → Defend → Retain. The goal is deep causal understanding with meaningful visualizations, actual engineering evidence and independently defended design decisions—not static HTML content or decorative diagrams.
